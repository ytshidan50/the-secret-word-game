Developer API & Game Rules

Documentation for the Secret Word party session game & REST API integration.

🎮 How the Speaking Game Works

  1. Step 1 (The Speaker): The speaker taps "Roll New Combo" to get a Topic (e.g. "Why cereal is cold soup") and a secret Word (e.g. "SPAGHETTI").
  2. Step 2 (The Speech): The speaker speaks on the topic for 1–2 minutes. They must weave the secret word into their speech at least 3 times naturally.
  3. Step 3 (The Audience Guess): Once the speaker finishes, the audience tries to guess what the secret word was!
  4. Step 4 (Reveal): The moderator taps "Reveal to Audience" to show the word and award points.

📡 REST API Endpoint: GET /api/combo

External apps, bots, and tools can call this endpoint to get a fun topic and secret word formatted as JSON.

Query Parameters

  • category (optional): all (default), fun, hottakes, awkward, roast, conspiracy.
  • level (optional): all (default), easy, medium, hard.

cURL Example

curl "https://your-site.vercel.app/api/combo?category=fun&level=medium"

JavaScript (fetch) Example

const res = await fetch("https://your-site.vercel.app/api/combo?category=fun&level=medium");
const { data } = await res.json();

console.log("Topic:", data.topic);
console.log("Secret Word:", data.word);
console.log("Rules:", data.rules);

🚀 Deploying to Vercel in 1 Minute

  1. Push this folder to a GitHub repository or drag-and-drop it into the Vercel Dashboard.
  2. Vercel automatically detects the static frontend and the serverless API in /api/combo.js.
  3. The clean URL /doc automatically serves this documentation page via vercel.json.
